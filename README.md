# DESAFIO

Nesta etapa, teremos um desafio técnico com os seguintes objetivos:

* Desenvolver uma aplicação simples (ex.: Hello World) para demonstrar a observabilidade da solução;
* Disponibilizar a aplicação publicamente;
* Publicar todo o projeto no GitHub;
* Implementar um pipeline de CI/CD;
* Realizar uma simulação de deploy da aplicação durante a apresentação.
* Caso queira implementar funcionalidades adicionais ou melhorias além do escopo solicitado, isso será considerado um diferencial positivo.

O prazo para entrega é de 5 dias corridos. Entregas antecipadas, acompanhadas de domínio técnico sobre a solução implementada, também serão avaliadas positivamente. Por favor, me confirme se deseja continuar no processo.

Assim que o projeto estiver concluído, me avise para alinharmos a apresentação.
É importante estar preparado para explicar as decisões técnicas, defender a arquitetura escolhida e apresentar o valor da solução construída.
Boa sorte e obrigado.
